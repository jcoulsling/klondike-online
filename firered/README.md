# The Hän FireRed source changes

`han-firered.patch` is a git patch for the pret `pokefirered` source (`git apply`). It holds the engine
and tool changes only. The translated text, the music, the Sylveon picture and the character pack are not in
it: whoever builds supplies those next to the `pokefirered` folder (see `setup.sh`).

This branch is separate from `main`, so the web page on Render is not touched.
